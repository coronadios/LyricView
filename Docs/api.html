Main components

  • LyricEngine — lifecycle and state orchestration
  • TimeEngine — playback timing and synchronization
  • ParserRegistry — format registration and parsing
  • PluginManager — extension registration and hooks
  • ScrollController — smooth scrolling and damping

Good OSS ergonomics

The public API is intentionally simple: create an engine, feed it existing or custom song data, attach a renderer, and let timing state drive the visual updates. That design helps contributors extend the system with minimal ceremony and without breaking the core contract.

For a contributor, the easiest way to make a meaningful improvement is to work in one layer at a time: parsing, timing, motion, or UI rendering.
