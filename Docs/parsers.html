Parser registry

Different lyric sources should be parsed by different functions. The engine should not hardcode the format.

engine.register_parser("lrc", parse_lrc)
engine.register_parser("json", parse_json)
parsed = engine.parse(data, parser_name="lrc")

Supported ideas

  • Plain text fallback
  • LRC format
  • Structured JSON
  • Custom format adapters

Contributor guidance

Parsers are a natural place for open-source contribution because they are independent and composable. A new format can be added by writing a parser function that converts raw content into the canonical Song structure while preserving timing metadata and fallback behavior.

This keeps the rest of the engine stable and avoids scattering format-specific logic across the playback or renderer code.
